# ASEA 빠른 업무 등록 — Chrome 확장 프로그램

전역 단축키 **Ctrl+Alt+R**로 다른 앱 사용 중에도 ASEA 업무를 즉시 등록할 수 있습니다.

---

## 설치 방법

### 1단계: 확장 프로그램 폴더 준비

이 `chrome-extension` 폴더 전체를 PC 어딘가에 복사해 두세요.

### 2단계: Chrome에 개발자 모드로 설치

1. Chrome 주소창에 **`chrome://extensions`** 입력 → Enter
2. 오른쪽 상단 **"개발자 모드"** 토글 켜기
3. **"압축 해제된 확장 프로그램을 로드합니다"** 클릭
4. 이 `chrome-extension` 폴더 선택 → 확인
5. 확장 프로그램 목록에 **"ASEA 빠른 업무 등록"** 이 나타나면 설치 완료!

### 3단계: 전역 단축키 설정 확인

1. Chrome 주소창에 **`chrome://extensions/shortcuts`** 입력
2. **"ASEA 빠른 업무 등록"** 항목에서
3. `Ctrl+Alt+R` 옆 **"전역"** 드롭다운이 **"전역"** 으로 설정되어 있는지 확인
   - 기본값이 "Chrome에서"인 경우 반드시 **"전역"** 으로 변경해야 다른 앱에서 작동

---

## 사용법

| 상황 | 동작 |
|------|------|
| 다른 앱 사용 중 `Ctrl+Alt+R` | Chrome이 앞으로 오고 ASEA 빠른 등록 창 열림 |
| ASEA 미로그인 상태 | 로그인 안내 → 로그인 완료 후 자동으로 빠른 등록 창 열림 |
| ASEA 탭이 닫혀 있을 때 | 새 탭으로 ASEA 열고 자동으로 빠른 등록 창 표시 |
| 확장 아이콘 클릭 | 팝업에서 상태 확인 + 열기 버튼 |

---

## 주의사항

- **Chrome이 실행 중**이어야 전역 단축키가 작동합니다 (Chrome 자체가 꺼져 있으면 불가)
- Windows 시작 시 Chrome 자동 실행을 설정해 두면 PC 켜자마자 단축키 사용 가능
  - Chrome 설정 → "시스템" → "Google Chrome이 닫혀 있을 때 백그라운드 앱 계속 실행" 켜기
- `Ctrl+Alt+R`이 Chrome 내부에서 겹칠 경우, 단축키를 `Ctrl+Shift+Alt+R` 등으로 변경 가능

---

## Chrome 백그라운드 실행 설정 (권장)

Chrome을 완전히 닫아도 백그라운드에서 계속 실행되도록 설정하면  
**Chrome 창 없이도** 단축키가 작동합니다:

1. Chrome → 오른쪽 상단 ⋮ 메뉴 → **설정**
2. 왼쪽 메뉴 → **시스템**
3. **"Google Chrome이 닫혀 있을 때 백그라운드 앱 계속 실행"** → 켜기
4. 이제 Chrome 창을 모두 닫아도 시스템 트레이에서 Chrome이 실행 중 유지됨

## v1.1.0 변경 사항

- **선택 텍스트 자동 일정화**: 웹페이지에서 `2026.10.6 13:00~14:00 회의`처럼 날짜(와 시간)가 포함된 글을 드래그한 뒤 **Ctrl+Alt+R**을 누르면 일정 추가 창이 자동 입력되어 열립니다.
  - 날짜만 있으면 종일 일정, 시작 시간만 있으면 1시간 일정, 날짜가 없으면 기존 빠른 등록 창(본문 자동 붙여넣기)이 열립니다.
- **ASEA 탭이 없을 때**: 새 탭 대신 작은 팝업 창으로 바로 열립니다.
- 업데이트 후 `chrome://extensions`에서 확장 프로그램을 **새로고침**해야 `activeTab` 권한이 적용됩니다.
- 단축키가 다른 앱에서도 동작하려면 `chrome://extensions/shortcuts`에서 Ctrl+Alt+R의 범위를 **전역(Global)** 으로 지정하고, Chrome 설정의 "Chrome을 닫을 때 백그라운드 앱 계속 실행"을 켜 두어야 합니다. (Chrome 프로세스가 완전히 종료되어 있으면 동작하지 않습니다.)
