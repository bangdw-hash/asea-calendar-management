# 교직원 AI 바이브 코딩 1차 교육 안내 및 실습자료
교육일: 2026년 11월 13일(금) / 60분 / Windows PC

## 1. 교육 목표
ChatGPT·Codex 또는 Claude·Claude Code를 활용해 자연어로 업무용 웹앱을 제작하고 수정한다. GitHub 저장소에 결과를 관리하고 AI 포럼에서 질문과 오류를 공유한다.

## 2. 도구 및 비용
ChatGPT와 Claude의 무료 채팅 기능은 사용량 제한이 있다. Codex는 계정별 제공 여부를 확인한다. Claude Code는 별도 이용 자격·구독 또는 API 과금이 필요할 수 있다. GitHub의 기본 저장소 기능은 무료로 시작할 수 있다. 유료 기능은 공통 실습의 필수 조건이 아니다.

## 3. 개발 환경
학교 공용 GitHub 계정이 교직원별 실습 저장소를 만들고 개인 GitHub 계정을 공동 작업자로 초대한다. 각자 자신의 저장소에서 작업한다. 기존 ASEA 운영 저장소는 교육 자료 참고용으로만 사용한다.

## 4. 디자인 기준
교육용 DESIGN_SYSTEM.md, AGENTS.md, css/tokens.css를 참고한다. 현재 기준은 schedule.html에서 확인한 색상·글꼴을 바탕으로 한 초안이며 학교 전체의 확정 표준은 아니다.

## 5. 실습 지시문
교직원이 사용할 업무용 메모 웹앱을 HTML, CSS, JavaScript로 만들어 주세요. 메모 등록, 수정, 삭제와 새로고침 후 데이터 유지 기능을 구현하세요. PC와 스마트폰에서 사용할 수 있도록 구성하고, 프로젝트에 DESIGN_SYSTEM.md와 AGENTS.md가 있다면 먼저 읽고 적용하세요. 작업 후 실행 방법과 변경 파일을 알려 주세요.

완성 후 '메모 검색 기능을 추가하되 기존 기능은 유지해 주세요'라고 요청한다. 기능을 확인하고 자신의 GitHub 저장소에 반영한다. 웹 배포는 실습 진행 상황과 계정 권한에 따라 시연 또는 후속 과제로 진행한다.

## 6. 질문 공유
AI 활용 포럼에 사용 도구, 작업 내용, 오류 메시지, 시도한 방법을 적는다. 화면 캡처를 첨부할 수 있으나 학생정보·비밀번호·API 키는 가린다.

## 7. 다음 시간 예고
다음 시간에는 AI가 웹페이지의 조회·입력을 지원하는 브라우저 업무 자동화를 소개한다. 개인정보가 없는 테스트 화면에서 시작하고 실제 학사정보시스템 적용은 별도 권한·보안 검토 후 진행한다.
