## 2. 저장 — 저장소 버튼 패턴

**원칙**: 사용자가 '저장했는지 모르는 상태'를 만들지 않습니다.

1. **자동 저장**: 입력 후 1.2초 디바운스(`UX.autosave(fn, node)`), 5분 주기 보조 저장(예산 입력판).
2. **상태 표시** `.ux-savestate`: 회색 점 '대기' → 주황 점 깜박임 '저장 중' → 초록 점 '저장됨 14:03' → 빨강 점 '저장 실패 — 다시 시도'. 헤더 오른쪽에 둡니다.
3. **저장 버튼**: 하단 고정 작업 바(`.ux-bottombar`)에 `취소(ghost) · 저장(primary)`. 눌리면 `.busy`로 바뀌어 중복 제출을 막습니다.
4. **변경 있음 경고**: 저장 전 이탈 시 `beforeunload` 확인. 저장 실패 시 `award_draft`처럼 임시 보관 후 복구 안내.
5. **동시 편집**: 줄 단위 버전·입력 중 표시·4초 변경 가져오기(예산 입력판). 충돌은 '확인 필요'로 직접 고르게 합니다.
6. **이력**: 변경은 지우지 않는 이력(`ticket_events`, `final_hist`)에 남기고 사유를 필수로 받습니다.
7. **내보내기도 저장의 일부**: 엑셀·PDF·인쇄는 항상 도구 모음에 노출합니다.

```js
var ss = UX.autosave(function(){ return fetch(...); }, document.querySelector('.ux-savestate'));
textarea.addEventListener('input', ss);
```

## 3. 책갈피(즐겨찾기)

- 아이콘: 24px 북마크 SVG, 평소 `#9AA3AB` 외곽선 → 활성 주황 `#ea580c` 채움. 버튼 32×32, `aria-pressed`로 상태 전달.
- 동작: 누르면 `scale(.88)` 눌림 → 즉시 토글 + 토스트('즐겨찾기에 추가했습니다'). 목록은 `UX.bookmarks(key).list()`(최근 추가 순).
- 저장: 기기 `localStorage`. 계정 간 공유가 필요하면 서버 테이블(예: `award_pref`처럼 키-값)로 옮기되, 키트의 `bind/toggle/list` 인터페이스는 유지합니다.
- 같은 인터페이스로 최근 본 항목·고정 항목도 만들 수 있습니다(제안, 저장소에 아직 구현 없음).
- 저장소 현황: 책갈피 전용 UI는 별도로 구현된 것이 없어 이 키트의 `UX.bookmarks`가 기준안입니다. 상장 편집기의 문서 탭(우클릭 메뉴·순서 변경)과 설문 작업 탭 바가 가장 가까운 기존 패턴입니다.

## 4. 삭제·되돌리기

- 즉시 삭제 후 **되돌리기 토스트**(5초)가 기본. 되돌릴 수 없는 삭제(영구 삭제·발급 취소)만 확인창 + 위험 버튼.
- 휴지통이 있는 화면(업무방·서식 관리)은 Del=휴지통, Ctrl+Z=되돌리기, 영구 삭제는 별도 확인.
- 확인창 문구: 대상 + 결과 + 되돌림 가능 여부('삭제하면 복구할 수 없습니다').

## 5. 드래그 앤 드롭

- 순서 바꾸기: 핸들 `cursor:grab`, 대상 위/아래 절반에 3px 주색 막대, 놓으면 즉시 반영 + 토스트.
- 칸반 열 드롭: 열에 `outline: 2px dashed 주색` + 연한 주색 배경(`.col.over`).
- 파일 올리기: 영역 점선 테두리, 드래그 진입 시 배경 연한 주색, 여러 개는 쌓아 파일별 진행 표시.
- 키보드 대체 수단(위/아래 버튼, 이동 메뉴)을 함께 제공합니다.

## 6. 오버레이

| 종류 | 등장 | 닫기 | 규격 |
|---|---|---|---|
| 모달 | `ux-pop .2s` (아래→위 8px, scale .98→1) | X·ESC·바깥 클릭 | 폭 min(620px,100%), 머리/본문/하단 3분할, 모바일은 아래 시트 |
| 서랍 | `ux-slide .25s` (오른쪽 24px) | 동일 | 폭 min(520px,100%), 높이 100% |
| 토스트 | `ux-rise .2s` | 2.6초(오류 4.5초) | 하단 중앙, `#1B2433`, 6px, 최대폭 90vw, 여러 개는 위로 쌓임 |
| 도움말 팁 | opacity .15s | 호버·포커스 해제 | 어두운 상자 12px, 최대 260px |
| 코치마크·명령 팔레트(⌘K) | 기존 페이지에 구현, 규격 동일 계열 | ESC | z-index 모달 이상 |

모달은 열릴 때 첫 입력으로 포커스를 옮기고, 닫히면 열기 전 요소로 복귀합니다. 배경 클릭 닫힘은 입력 중인 폼에서는 끕니다.

## 7. 접기·펼치기

- 단순 접기: `.collapsed`로 본문 `display:none`, 상태 저장.
- 높이 애니메이션 필요 시 아코디언: `grid-template-rows: 0fr → 1fr` (.32s). `height:auto`를 직접 전환하지 않습니다.
- `aria-expanded`를 항상 갱신합니다.

## 8. 키보드

| 키 | 동작 |
|---|---|
| ESC | 모달·서랍·메뉴 닫기, 편집 취소 |
| Enter / Space | 접기 머리·버튼 실행 |
| ← → | 탭 이동 |
| Del / Ctrl+Z / F2 | 삭제(휴지통) / 되돌리기 / 이름 변경(서식 관리) |
| ⌘K | 명령 팔레트 |
| T R L B P F5 | 상장 편집기 한 글자 단축키(글상자·사각형·선·표·속성·셀 선택) |
| Space + 드래그 | 편집 화면 이동 |

## 9. 애니메이션 목록(저장소 공통 이름)

`spin`(.6~.8s linear) · `fadeIn`(.15~.2s) · `slideUp`(.25s) · `toast-in`(.18s) · `navSheetUp`(.18s ease-out) · `mobile-sheet-in`(.3s cubic-bezier(.32,.72,0,1)) · `badge-pulse`(1.5s) · `flash`(1.6s). 새 코드는 키트의 `ux-*` 이름을 씁니다. 총 약 90개 키프레임이 페이지별로 흩어져 있으며 같은 효과의 중복이 많습니다(`07-token-audit.md`).

## 10. 접근성 보장

모션 줄이기 설정 시 전환·애니메이션 .01ms, 포커스 링 제거 금지, 색 외 텍스트 병기, `role`·`aria-*` 위 표 참조, 토스트는 `aria-live`.
