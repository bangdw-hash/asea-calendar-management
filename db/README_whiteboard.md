# 실시간 수업 노트(whiteboard.html) 설치·사용 안내

## 주소
- 학생 입장: `whiteboard.html` (수업 코드 4자리 입력) 또는 `whiteboard.html?r=수업코드`
- 교수자: `whiteboard.html?mode=teacher` (비밀번호 로그인)
- 빔프로젝터용 학생 화면: `whiteboard.html?r=수업코드&view=1` (교수 화면만 따라가며 조작 버튼 없음)

## 서버 설치 (이미 적용된 경우 생략)
1. Supabase SQL Editor에서 `db/whiteboard_schema.sql` → `whiteboard_schema_2.sql` → `whiteboard_schema_3.sql` → `whiteboard_schema_4.sql` 순서로 실행 (여러 번 실행해도 안전)
2. 교수자 비밀번호 등록 — 둘 중 하나 (이미 등록했다면 생략)
   - 상장 출력기와 같은 비밀번호: `update wbd.secret set admin_hash = (select admin_hash from awd.secret where id = 1) where id = 1;`
   - 새 비밀번호: `update wbd.secret set admin_hash = extensions.crypt('<비밀번호>', extensions.gen_salt('bf')) where id = 1;`
3. 저장소 버킷 `wb-files`(공개 읽기, PDF 50MB 이하)는 스키마 파일이 함께 만듭니다.

## 수업 진행
1. 교수자 화면에서 새 수업을 만들면 4자리 수업 코드가 발급됩니다.
2. 「PDF 올리기」로 교안(PPT는 PDF로 저장) 업로드 → 「입장 안내」로 QR·코드를 화면에 띄웁니다.
3. 쪽 넘김은 교수자 화면의 ←/→ 키 또는 버튼. 학생은 기본으로 따라가며, 자유 이동 후 「교수 화면으로 돌아가기」「내가 보던 N쪽으로 돌아가기」를 쓸 수 있습니다.
4. 노트는 입력하는 즉시(약 0.2~0.3초) 학생 화면에 나타납니다. 모바일은 아래 「노트」 버튼의 팝업으로 표시됩니다.
5. 링크는 「보내기」를 누르면 학생 화면에 알림과 함께 나타납니다.
6. 이해도 신호는 학생이 「이해했어요/어려워요」를 누르면 교수자 화면에 인원수로 집계됩니다.

## 자료·파일
- PDF는 여러 개를 올려 탭으로 전환합니다. 교수자가 전환하면 학생 화면도 따라가며, 학생은 자료 탭으로 자유롭게 이동하고 「교수 화면으로 돌아가기」로 복귀합니다.
- 파일을 교수자 화면 아무 곳에나 끌어다 놓거나(여러 개 가능) 「자료 추가」로 올립니다. PDF는 수업 자료, 그림·텍스트·문서(docx·xlsx·pptx·hwp 등, 50MB 이하)는 첨부 자료가 되어 학생이 내려받을 수 있습니다. PPT는 화면에 표시되지 않으므로 PDF로 저장해 올립니다.
- 「학생 내려받기 허용」을 끄면 학생 화면의 내려받기 목록이 숨겨집니다. 자료 삭제는 「제외(숨김)」로 처리됩니다.

## 학생 편의 기능
- 확대: 버튼, Ctrl+휠, 두 손가락 벌리기, 손 도구로 끌어서 이동 (본인 화면에만 적용)
- 쪽 목록(썸네일), 글자 드래그 복사·「이 쪽 글자 복사」·노트 복사·링크 주소 복사, 노트의 「복사 블록」
- 쪽별 내 메모(이 PC 브라우저에만 저장, 텍스트 저장), 노트·링크 텍스트 저장
- 교수자 레이저 포인터와 클릭 표시, 교수자가 따로 움직이면 쪽 번호 깜빡임(모바일은 짧은 진동)

## 타이머·화면 설정·발표 모드
- 타이머·휴식: 교수자 오른쪽 패널의 「휴식 5·10·15·20분」 버튼을 한 번 누르거나 분을 입력해 「타이머 시작」. 학생 화면 위쪽에 작은 표시만 나타나 보던 화면을 그대로 쓸 수 있고, 마지막 1분은 주황색, 끝나면 10초간 「종료」가 표시됩니다(모바일 진동). 나중에 들어온 학생도 남은 시간이 표시됩니다.
- 학생 화면 설정(헤더의 Aa): 글자 크기 5단계, 어둡게 보기. 이 PC 브라우저에 기억됩니다.
- 발표 모드(교수자 「발표 모드」 버튼): 슬라이드를 전체화면으로 크게 보고, 하단 막대에서 쪽 이동·접속/이해/어려움 인원·타이머·노트 서랍·나가기를 씁니다. Esc로 나갑니다. 방향키·Ctrl+휠 확대·포인터는 그대로 동작합니다.

## 학생 도움 요청(대화)
- 학생은 입장할 때 **이름을 등록**합니다(필수, 이 PC에 기억, 화면 설정(Aa)에서 변경). 교수자의 「접속 N명」을 누르면 접속 학생 명단이 보입니다.
- 학생: 「도움 요청」 → 유형(오류/막힘/질문) 선택 → 글·사진 전송. 사진은 Ctrl+V 붙여넣기, 파일 선택·끌어놓기, 「내 화면 찍기」(브라우저 화면 공유 허용 후 1장 캡처)를 지원합니다. 오류 문구는 「코드 모양 그대로 보내기」로 줄바꿈·들여쓰기가 유지됩니다. 보낸 쪽은 자동 첨부됩니다.
- 교수자: 새 요청이 오면 오른쪽 위에 알림 카드(최대 3장)가 뜹니다. 「처리 시작」 또는 「도움 요청」 보드(대기·확인 중·해결됨, 카드를 끌어 상태 변경)에서 대화로 답합니다. 프롬프트·이미지를 보내면 학생 화면에 **복사 버튼**(글자 복사, 이미지는 클립보드 복사·저장)이 붙어 한 번에 가져갑니다.
- 기록은 「기록 저장」(텍스트)으로 내려받고, 「기록 지우기」를 누를 때까지 보관됩니다(지우면 이름·내용·사진 연결이 비워집니다).

## 쪽별 이해도
- 학생이 「이해했어요/어려워요」를 누르면 그 쪽(자료·쪽 번호)에 기록됩니다. 쪽이 바뀌면 신호가 새로 시작됩니다.
- 현재 쪽에 어려움이 1명 이상이면 교수자 화면에 「어려움 존재」 경고가 뜨고, 3명 또는 접속자의 10% 이상이면 강한 경고(주황 깜빡임)가 됩니다.
- 「쪽별 집계」에서 어려움이 많았던 쪽을 보고 텍스트로 저장합니다. 학생 이름은 저장하지 않고 인원수만 기록합니다.

## 구조·주의
- 실시간: Supabase Broadcast(교수자 키 해시 검증) + 학생 화면 4초 폴링 백업. 연결 상태는 학생 화면 오른쪽 위에 표시됩니다.
- 학생은 읽기 전용이며 서버에 쓰는 것은 이해도 신호뿐입니다. 이름 등 개인정보는 받지 않습니다.
- 수업 코드는 4자리라 코드를 아는 사람은 누구나 입장할 수 있습니다. 민감한 자료는 올리지 마십시오.
- 수업방 삭제 기능은 없으며 「수업 종료」로 비활성화합니다. 오래된 수업방은 SQL로 정리합니다.
- Supabase 실시간 동시 접속·월 메시지 한도는 요금제에 따라 다릅니다(공식 문서 확인 필요).
