# 03. 표·그래프·결과 화면

## 1. 표

| 항목 | 값 |
|---|---|
| 래퍼 | 흰색·1px 테두리·6px·`overflow:auto`, 세로 스크롤 시 `max-height` |
| 머리 | 배경 `#F7FAFC`, 12px/600 보조색, `position:sticky; top:0`, `white-space:nowrap` |
| 셀 | 패딩 8×10, 13px, 아래 1px `#E8EAED`, 마지막 행 선 없음 |
| 숫자 열 | 오른쪽 정렬, `tabular-nums`, 줄바꿈 금지 |
| 정렬 가능 머리 | 호버 시 주색, 현재 방향은 ▾/▴ |
| 클릭 행 | `cursor:pointer`, 호버 `#E8F0FE` |
| 그룹 머리 행 | 배경 `#F1F5F9`, 700 |
| 저장 중/완료 행 | 저장 중 `#FFFBEB`, 완료 `#dcfce7`(.6s 서서히 사라짐) |

예산 입력표(budget-app.css): 패딩 7×9, 최소폭 900~1100px 가로 스크롤, 코드 열 104px·금액 열 116~136px 고정, 그룹 행 3단계(합계 `#F1F5F9`, 상위 연한 주색, 하위 들여쓰기 22px), 펼침 행은 점선 상자. 결과표 `table.t`(aseasurvey)도 머리 고정·tabular-nums입니다.

**모바일**: 가로 스크롤을 유지하고 첫 열을 고정하거나, 카드 목록으로 바꿉니다(task.css 타임라인은 이름 열 `position:sticky; left:0`).

## 2. KPI 타일

`grid-template-columns: repeat(auto-fit, minmax(150px,1fr))`, 간격 10px. 업무 화면은 4열 → 640px 이하 2열. 변동 표시 `.up`(빨강)·`.down`(파랑), 단위는 12px 보조색.

## 3. 그래프 — 마크업으로 그리는 4종 (ui-kit.css)

| 그래프 | 클래스 | 규격 |
|---|---|---|
| 미터 | `.ux-meter > i` | 높이 10px, 채움 주색, 초과 시 빨강, 너비 전환 .25s |
| 가로 막대 | `.ux-bar` | 3열 그리드 `110px 1fr 44px`, 막대 높이 14px, 값은 오른쪽·tabular-nums |
| 누적 막대 | `.ux-stack-bar` | 높이 18px, 구간 색은 의미색 |
| 히스토그램 | `.ux-hist` | 높이 120px, 막대 위쪽만 둥글게, 라벨 11px |
| 히트맵 | `.ux-heat` | 정사각 셀 6px, 값 색 단계(연한→진한), 글자 흰색 |

모든 막대는 `transition: width/height .25s`. 값 라벨을 항상 병기하고(색만 의존 금지) 0 값도 표시합니다.

## 4. 그래프 — SVG 직접 작성 (저장소에서 쓰는 방식)

- 도넛: `r=15.9`(둘레 100) 원에 `stroke-dasharray="값 100-값"`·`stroke-dashoffset="25"`, 가운데 텍스트. 배경 트랙 `#EEF1F4`.
- 산점도·분포(비교 분석실 `aseasurvey-admin-lab.js`): 축 `#CBD5DF`, 점 반지름 3~4, 기준선 점선, 선택 집단은 주색·나머지 회색, 호버 시 툴팁. 슬라이더로 기준값을 바꾸면 즉시 재계산(브라우저 안에서만).
- 색은 주색+의미색 3개 이내, 눈금 11px 보조색. 차트 라이브러리는 쓰지 않습니다(저장소 무빌드 원칙).

## 5. 결과 화면 공통 도구 (설문 규칙)

모든 결과 화면 상단 도구 모음에 **엑셀(`gxlsx`)·현재 화면 PDF(`gpdf`)·인쇄(`gprint`)**를 기본 제공합니다. 새 결과 탭을 만들 때 이 세 버튼이 없으면 완성으로 보지 않습니다. 점수는 **5점이 최고**(긍정 4·5, 부정 1·2), '유효 응답'은 주의 확인을 통과하고 한 줄 응답이 아닌 것입니다.

결과 화면 구성(aseasurvey-admin): 요약 KPI → 분석 메뉴(결과·비교·조건 검출·같은 과목·참여 현황·종합 보고서·회차 비교·주제 연결·우선순위·개선 과제·비교 분석실) → 표·그래프 → 도구 모음. 교수별·반별·계열별은 목록→정렬→리포트 PDF/ZIP/인쇄 순서입니다.

## 6. 단계별 로딩·갱신

폴링 화면(업무방 6초, 수업 노트 4초)은 변경 행에 `.ux-flash`(1.6초 연한 주색 → 투명)를 줍니다. 저장 중 행은 `saving`→`saved` 클래스로 색을 바꿉니다.
