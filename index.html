🏢 관리실 인원 등록 관리자

관리실 당직 인원을 등록합니다. 관리실 포털에서 확인·배정됩니다.

🌐 앱 기본 URL (커스텀 도메인)

커스텀 도메인을 연결한 경우 여기서 URL을 변경하면 QR 코드 링크 등에 자동 반영됩니다.
끝에 /를 포함해야 합니다. 예: https://simmanager.asea.or.kr/

🔗 QR 체크인 서버 URL

QR 입출입 기록을 저장하려면 Google Apps Script 프록시 URL을 입력하세요. gas_checkin_proxy.gs 파일을 GAS에 배포 후 웹앱 URL을 붙여넣습니다.

🗑️ 직원 데이터 초기화 관리자

직원 시트의 모든 데이터를 완전 삭제합니다. 헤더(1행)는 유지됩니다. 중복 업로드 등으로 데이터가 오염된 경우 초기화 후 CSV를 1회 재업로드 하세요.

🗄️ Sheets DB 초기화 관리자

Google Sheets에 필요한 모든 시트(직원·업무·업무수신·알림로그·시설·대관예약·차량·차량예약·작업지시·관리실인원·공간관리·입출입기록·입출입사용자)와 헤더를 자동으로 생성합니다. 최초 1회만 실행하면 됩니다.

🏢 시설(건물/호실) 관리 관리자

대관 가능한 건물과 호실을 등록/수정합니다. 등록 후 대관업무 탭에서 예약할 수 있습니다.

🚗 차량 관리 관리자

차량을 등록/수정합니다. 등록 후 차량관리 탭에서 예약할 수 있습니다.

☁️ 설정 클라우드 동기화

API 키·웹훅 URL·수신자/부서 목록 및 추출/공유 이력이 Google Drive에 자동 저장됩니다. 로그인하면 어느 기기에서나 동일한 이력과 설정이 자동으로 불러와집니다.

Claude API 키 (일정발췌 · 빠른 업무 등록 AI 분석)

⚠️ API 키는 브라우저 localStorage에만 저장되며 외부로 전송되지 않습니다. console.anthropic.com에서 발급하세요.

Gemini API 키

GitHub Token (일정 공유 페이지 자동 생성)

⚠️ localStorage에만 저장됩니다. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens에서 발급. Contents: Read and write 권한 필요.

Make.com 웹훅 URL (이메일 예약 서버 발송)

Make.com 시나리오 1의 CustomWebHook 모듈 URL을 입력하세요. 이메일 예약 시 브라우저가 닫혀도 자동 발송됩니다.

내 캘린더 표시 설정

표시할 캘린더를 선택하고 색상을 지정하세요. 여러 캘린더가 색상별로 구분 표시됩니다.
