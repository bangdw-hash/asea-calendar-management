# 범용 설문(행사·교직원 설문 등) 사용 안내

별도 개발 없이 관리자 화면(`aseasurvey-admin.html`)에서 설문을 만들고 배포합니다. DB 6단계(`db/survey_schema_6.sql`)가 설치되어 있어야 합니다.

## 1. 설문 만들기 — 세 가지 방법

| 방법 | 적합한 경우 |
|---|---|
| **AI로 설계** | 기존 설문지(이미지·PDF·docx·hwpx·xlsx·txt)나 요청 글이 있을 때 |
| **일반 설문(빈 양식)** | 처음부터 직접 문항을 구성할 때 |
| **이전 설문 불러오기** | 지난 설문을 복제해 고칠 때 |

### AI 설계 3단계
1. **자료 입력** — 파일 여러 개와 요청 글을 넣습니다. (jpg·png·PDF는 AI가 직접 읽고, docx·hwpx·xlsx는 화면에서 텍스트로 변환)
2. **제안 확인·수정** — AI는 설문을 만들지 않고 「설계 제안」만 냅니다. 문항별 추천 형식과 이유, 학생 화면 예시(눌러 볼 수 있음), 개선 제안(반영 버튼)이 표시됩니다. 형식·문구·필수·순서를 직접 고치거나 「AI에게 수정 요청」으로 다시 받을 수 있습니다.
3. **만들기(개발 시작)** — 이 버튼을 눌러야 비로소 설문이 생성됩니다.

## 2. 문항 형식 (34종)
입력(단답·장문·숫자·이메일·전화·URL·패턴(학번 등)·날짜·날짜시간·시간) / 선택(객관식·드롭다운·체크박스·이미지 선택·5점 척도·예아니오·선형 배율·별점·NPS·슬라이더) / 표·순위(객관식 그리드·체크박스 그리드·순위·합계 배분) / 특수(파일·사진 촬영·전자서명·주소(도로명 검색)·현재 위치·QR 스캔·동의) / 안내(설명 글·이미지·동영상)

- **주소**: 카카오(다음) 우편번호 서비스로 도로명 검색 → 우편번호·도로명 확인된 값만 저장. 「현재 위치로 찾기」는 동의 후 브라우저 위치를 사용합니다(역지오코딩은 참고용이므로 검색 선택으로 확정).
- **분기**: 문항·영역마다 「표시 조건」(모두/하나라도 만족) 설정.
- **퀴즈**: 문항에 정답·배점 지정 → 제출 후 점수 표시(설정), 결과에서 정답률. 정답은 학생에게 내려가지 않습니다.
- **정원**: 설문 전체 선착순(`설문 설정 > 선착순 정원`) 또는 선택지별 정원. 마감되면 선택 불가·제출 거절.
- **섞기**: 선택지 순서 무작위.

## 3. 설문 유형
- **과목별 평가**: 반 선택 → 과목마다 반복 응답(기존 교육과정 개선 설문). 추첨번호·성실응답 점검 사용.
- **일반 설문**: 1인 1회(같은 기기 중복 제출 방지). 영역별 단계 이동 또는 한 화면. 추첨번호 표시는 `설문 설정`에서 선택(기본 표시 안 함).

## 4. 결과
- 일반 설문: 요약(KPI·일별 추이·정원·퀴즈) / 문항별(형식마다 알맞은 집계, NPS·그리드·순위·배분 포함) / 개별 응답(서명·첨부 열람, 집계 제외) / 엑셀.
- 과목별 평가: 기존 대시보드(과목 히트맵·교수별 현황판·추첨).

## 4-1. 제출 후 수정 · 응답자 식별 · 완료 후 안내 (설문 설정)
- **제출 후 응답 수정**: 허용 안 함 / 24시간 / 3일 / 설문 마감까지. 같은 기기에서만 가능, 추첨번호 유지, 선택지 정원은 본인 응답을 제외하고 계산. (DB 7단계 필요 — `db/README_survey.md` 7단계)
- **응답자 식별**: 익명 / 기명(이름·소속·개인정보 동의 문항 자동 추가).
- **제출 완료 후 안내**: 기본 / 링크 버튼 / 참여 확인서(이미지) / 링크+확인서.
- **결과 리포트**: 일반·과목별 모두 「리포트」(교차 필터), 과목별은 「과목·교수 현황판」(기존), 「이력 비교」(다른 설문과 문항 평균 비교).

## 4-2. 실시간 학생 화면 미리보기
관리자 화면 오른쪽의 「미리보기」 도크는 모든 화면(설문 목록, 새 설문 만들기의 기본 양식·이전 설문 불러오기, AI 설계 제안, 개요·안내문·문항·과목·디자인·결과·추첨·버전 탭)에서 열 수 있습니다. 입력하는 즉시 반영되고, 편집 중인 문항·영역·설정(추첨번호·수정 허용·완료 후 안내)의 위치로 자동 이동합니다. 눌러서 입력해 볼 수 있으나 저장되지 않습니다.

## 4-3. 과목·교수 AI 불러오기 (과목별 평가)
「과목·교수」 탭의 **AI로 불러오기**에서 시간표·수강편성표·교육과정표 파일(엑셀·PDF·이미지·docx·hwpx·txt, 여러 개)을 올리면 AI가 반별 과목·구분·담당교수 표로 정리합니다.
- 표준 양식 엑셀/CSV는 AI 없이 바로 읽습니다.
- **등록 전 확인·수정**: 모든 칸 직접 수정, 행 추가·삭제, 일괄 변경(예: 교수명 통일), 중복 정리, 신규/갱신/동일 표시, 빈 칸·중복이 있으면 등록 잠금.
- 등록 방식: 추가·갱신 / 전체 교체(응답 기록 보존). 등록 후에도 목록에서 건별 수정 가능.

## 4-4. 과목·교수 보기와 반×과목 등록
- 「과목·교수」 탭 상단에서 **목록 / 교수별 보기 / 반별 보기**를 전환합니다. 교수별 보기는 교수 한 명이 맡은 과목·반을 한눈에 보여 주고, 교수 미지정 과목·표기가 비슷한 이름(예: 김교수/김교수님)을 경고하며 이름을 한 번에 바꿀 수 있습니다.
- **반 × 과목 표로 만들기**: 계열·학년·반 목록(A~D 등)과 과목 목록을 한 번만 입력하고, 반마다 개설 여부·담당교수만 조정하면 모든 반에 펼쳐집니다. 이후 확인·수정 단계를 거쳐 등록합니다.

## 4-5. 길잡이와 도움말
설문 화면 위의 **진행 단계(안내문 → 문항 → 과목·교수 → 대상 인원 → 테스트 → 정식 시작)**와 「다음 할 일」 안내가 현재 상태를 보고 자동으로 바뀝니다. 어려운 항목 옆의 **?** 에 마우스를 올리면 풀어 쓴 설명이 나옵니다. 문항 편집에서는 자주 쓰는 설정만 보이고, 조건에 따라 보이기·정답(퀴즈)·문항 ID는 「고급 설정」에 있습니다.

## 4-6. 새 설문 만들기와 양식 라이브러리

- **새 설문 만들기**는 카드 갤러리입니다. 분야(수업·학생·행정·취업·조직·시설·행사·정책·성과/인증·신청/출석/퀴즈) 칩으로 거르거나 검색해 카드를 누르면 오른쪽 미리보기에 학생 화면이 바로 표시됩니다. 제목을 넣고 「이 양식으로 만들기」를 누릅니다.
- 설문의 **응답 방식**은 두 가지뿐입니다. 1인 1회 / 과목별 반복. 설문의 목적(행사·상담·신청 등)은 분야 카드로 고르며, 기능(추첨·정원·퀴즈·수정 허용 등)은 설문 설정 스위치로 켭니다.
- **양식 라이브러리**: 양식 1개 = 이름 + 버전 여러 개입니다. 설문 화면 「양식으로 저장」(새 양식 / 기존 양식의 새 버전), AI 설계 마지막 단계의 「양식 라이브러리에도 저장」으로 쌓입니다. 저장되는 것은 문항·설정·안내문·디자인뿐이며 응답·과목·인원은 저장되지 않습니다.
- 버전 관리: ★ 기본 버전 지정, 버전 비교(문항 추가·삭제·수정, 설정 변경), 편집 → 새 버전(이전 버전 유지), 다른 이름으로 복사, 버전·양식 삭제(마지막 버전은 삭제 불가).
- 라이브러리 화면의 「기본 양식 55종」 탭에서 필요한 양식만 체크해 「선택 복사」하면 내 양식(v1)으로 저장됩니다. 일괄 복사는 없으며, 같은 이름이 이미 있으면 건너뜁니다.
- 양식은 설문으로 **복사**되므로 양식을 고쳐도 이미 만든 설문에는 영향이 없습니다.
- 미리보기는 「폰 화면 / PC 화면」 탭으로 전환합니다.

## 4-7. 연동 목록 설문 (일괄 데이터 업로드)

- 새 설문 만들기 → 「연동 목록 설문 (일괄 업로드)」. 교강사·과목, 시설, 행사 프로그램, 부서처럼 **응답 대상이 되는 목록이 많은 설문**을 엑셀로 한 번에 연동합니다. 학생은 올려 둔 목록에서 대상을 고르고, 대상마다 같은 문항에 응답합니다.
- 설계 화면: ① 시작 유형(교강사·과목 / 시설 / 프로그램 / 부서 / 직접 구성) 또는 「AI 설계」(요청 글 또는 가지고 있는 엑셀로 열 구성 자동 제안) → ② 열 이름·사용 여부·예시 값 편집 → ③ 엑셀 양식 예시도(실시간) → ④ 문항 요약 → 「엑셀 양식 다운로드」 / 「이 구성으로 설문 만들기」.
- 「AI 추천 기능」은 현재 구성에 어울리는 열 변경·문항 추가·추첨번호 발급을 제안하며, 「적용」으로 한 번에 반영합니다.
- 열은 최대 6개(분류 1~3단계, 대상 이름, 보조 구분, 담당자)입니다. 쓰지 않는 열은 학생 화면과 양식에서 빠집니다. 담당자 열의 이름은 학생 화면에 과목과 함께 표시되고 결과 집계에도 쓰입니다.
- 설문을 만든 뒤 「○○ 목록」 탭에서 엑셀 업로드·붙여넣기·AI 불러오기(임의 형식 파일 자동 매핑)로 등록합니다. 등록 전 미리보기에서 신규·갱신·오류를 확인합니다.
- 한계: 결과·교수별 보기 일부 화면은 아직 「과목·교수」 용어로 표시됩니다.

## 4-8. AI 구간 설계 · AI 자문 (문항 탭)

- 문항 탭 위쪽 「AI 구간 설계」 → 문항 사이의 「＋」 줄(어느 문항 아래·어느 문항 위)을 누릅니다. 한 곳은 그 자리에 추가, 같은 영역의 두 곳은 그 사이를 대상으로 하며 「유지하고 보완」 또는 「새로 설계해 교체」를 고릅니다.
- 하단 막대에 요청(예: 「시설 만족도 5점 척도 3개」)과 개수를 입력하고 「AI로 설계」를 누르면, 제안 문항이 검토 창에 표시됩니다. 문구·선택지·필수 여부를 고치거나 문항을 삭제한 뒤 「반영」합니다. 반영 후에는 기존 문항 편집기에서 그대로 수동 수정하며, 「방금 AI 반영 되돌리기」로 되돌릴 수 있습니다. 저장 버튼을 눌러야 설문에 확정됩니다.
- 「AI 자문」은 막히는 부분을 적으면 현재 설문 구조를 보고 조언하고, 바로 구간 설계로 이어갈 수 있는 제안을 줍니다.
- 구간은 같은 영역 안에서만 지정할 수 있습니다. AI 결과는 반드시 관리자가 검토한 뒤 반영됩니다.

## 4-9. 배포 전 점검 (감사)

- 설문 화면의 「배포 전 점검」 탭에서 정식 시작 전에 설계를 점검합니다. 결과는 오류(배포 전 해결) · 주의 · 참고로 나뉘고, 연동성 · 중복성 · 누락성 · 논리 · 설정 · 개인정보 · 표현 · 응답 부담 분류로 묶입니다.
- **규칙 점검**(즉시, AI 없음): 연동 목록 비어 있음·예시 행 등록·담당자 미입력·같은 이름의 표기 불일치·목록과 맞지 않는 대상 인원, 같은 문구·비슷한 문항·선택지 중복, 빈 영역·제목·안내 누락, 존재하지 않거나 뒤쪽 문항을 가리키는 분기 조건, 퀴즈 정답·통과 점수 오류, 개인정보 동의 누락, 일정·테스트 모드, 예상 응답 시간(추정).
- **AI 정밀 점검**: 설문 구조·설정·연동 데이터 통계와 규칙 점검 결과를 AI 감사관이 읽고, 규칙으로 잡기 어려운 중복·누락·모순·이중 질문·안내문과 문항의 불일치를 추가로 지적하며 빠진 문항을 제안합니다. 제안은 「AI 구간 설계」로 바로 이어집니다. AI 의견은 참고용이며 최종 판단은 관리자가 합니다.
- 각 지적에서 해당 문항·탭으로 바로 이동할 수 있고, 「보고서 복사」로 점검 내용을 복사할 수 있습니다.
- 「시작·배포」 탭의 정식 시작 확인 항목에도 규칙 점검 결과(오류·주의 건수)가 표시됩니다.

## 4-10. 양식별 진행 순서와 팁박스

- 새 설문 만들기에서 양식을 고르면 하단 막대에 「만든 뒤 진행: 1. 문항 확인 → 2. 과목 일괄 등록 → …」 한 줄이 표시되고, 「자세한 순서」에서 단계별 설명을 봅니다. 양식의 특징(연동 목록·퀴즈·정원·기명·첨부 문항)에 따라 필요한 단계만 나옵니다.
- 설문 화면 위쪽 「다음 할 일」 길잡이도 같은 순서(안내문 → 문항 → 목록 등록 → 테스트 → 배포 전 점검 → 정식 시작)를 따릅니다.
- 각 탭 맨 위의 「이 탭에서 할 일」 팁박스에 그 탭의 작업 순서가 나옵니다. 「접기」로 접으면 기억되고, 「이 탭 안내 보기」로 다시 펼칩니다.

## 4-11. 다음 학기 운영 (목록만 새로 올리기)

1. 설문 목록의 지난 설문 카드에서 「복제」 → 새 제목·학기를 입력하고 **「비우고 새 학기 목록을 올립니다」**를 선택합니다. 문항·안내문·디자인·설정은 그대로 복사되고, 과목·교수 목록과 배포 인원은 비워집니다. (응답·추첨은 복사되지 않습니다.)
2. 자동으로 「목록」 탭이 열립니다. 새 학기 편성표(열: 계열·학년·반·과목명·구분·담당교수)를 엑셀로 올립니다. 이미 목록이 있는 설문에서는 「전체 교체」를 고르면 새 목록으로 바뀝니다.
3. 「대상 인원」(선택) → 「배포 전 점검」 → 테스트 → 「정식 시작」 순서로 진행합니다.
- 같은 편성으로 다시 운영할 때는 「그대로 복사」를 고르십시오.
- 양식 라이브러리의 「교과목·교강사 평가」(v2)로 새 설문을 만들 때도 같은 방법으로 목록만 올리면 됩니다.

## 4-12. 학생 응답 화면 방식 — A(과목별 칸) / B(질문별 표)

- 연동 목록(과목별 반복) 설문의 「설문 설정 → 학생 응답 화면 방식」에서 고릅니다. 설문 데이터·결과 집계는 두 방식이 같습니다.
- **A. 과목별 칸**: 과목마다 칸을 펼쳐 그 과목의 모든 문항에 응답합니다. (기본)
- **B. 질문별 표**: 질문마다 학생이 수강하는 모든 과목이 표로 나열되고, 과목별로 체크 칸을 눌러 응답합니다. 영역(II 수업 전 … VI 학습 성과) 순서로 질문이 이어집니다.
  - 각 과목은 한 줄(과목명·구분·교수)로 표시되고, 질문에는 영역별 번호(Ⅲ-1., Ⅲ-2. …)가 붙습니다.
  - 5점 척도와 단일·복수선택형(보기 8개 이하)은 체크 표로 표시됩니다. 보기가 길거나 6개 이상이면 열 머리글을 번호(1·2·3…)로 줄이고 표 위에 보기 설명을 함께 보여 줍니다. (예: Ⅳ 참여형 수업 운영, Ⅶ 교육윤리)
  - 선택 서술형 의견은 질문 앞에 과목·교수 칩이 나열되며, 의견을 남기려는 과목만 눌러 작성합니다. 작성하지 않아도 제출할 수 있고, 작성 후 선택을 해제하면 삭제 여부를 확인합니다.
  - 필수 서술형 등 표로 만들 수 없는 문항은 질문 아래 과목별 입력칸으로 표시됩니다.
  - 모바일에서 표가 화면보다 넓으면 좌우로 밀어 볼 수 있고(과목명 칸은 고정), 안내 문구가 나타납니다.
  - 기본 정보와 공통 문항은 A와 같은 기존 형태로 표시됩니다.
- 새 설문 만들기 갤러리에는 같은 문항의 「교과목·교강사 평가 A형(교과목 중심형)」과 「B형(질문 중심형)」 카드가 따로 있습니다. B형 카드로 만들면 화면 방식이 처음부터 B로 설정되며, 만든 뒤에도 설문 설정에서 바꿀 수 있습니다.
- 관리자 미리보기(오른쪽 도크)는 「폰 화면 / PC 화면」 탭으로 전환해 두 방식 모두 확인할 수 있습니다.

## 4-13. 교수명 숨김과 결과 「비교」 탭
- 「설문 설정 → 학생 화면의 담당 교수명 → 숨김」으로 두면 학생에게는 과목명·구분만 보입니다. 정식 응답에서는 서버(DB 10단계)가 교수명을 학생 화면으로 보내지 않고, 결과 화면의 교수별 집계는 그대로 사용합니다.
- 결과 보기 → **비교** 탭: 비교 기준(계열·학년·반·교수·과목·이론/실습)과 조회 항목(종합·영역별·문항별)을 고르면 막대 비교와 순위표가 나옵니다. 표의 열 제목을 누르면 그 열 기준으로 정렬되고(다시 누르면 오름·내림 전환), 이름 검색과 위쪽 필터(계열·학년·반·교수·과목 등)를 함께 쓸 수 있습니다. 응답 5건 미만은 「참고용」으로 표시됩니다.
- 막대 축을 「차이 확대」로 바꾸면 최저점~5점 구간을 늘려 보여 주므로, 차이를 키워 보여 준다는 점을 감안해 비교용으로만 보십시오.

## 4-14. 유효 응답만 보기와 엑셀
- 결과 보기 위쪽 「응답 범위(유효성)」에서 **유효 응답만**을 고르면, 점검 문항(「전혀 아니다」 등 정해진 값을 골라야 하는 문항)을 맞게 답하고 모든 문항을 같은 값으로 찍지 않은 응답만 집계합니다. 점검 문항이 없는 설문은 직선 응답만 걸러집니다.
- 이 선택은 리포트·비교·문항 상세·개별 응답·과목·교수 현황판·이력 비교 **모든 화면이 함께** 따릅니다. 화면을 옮겨도 유지됩니다. (개별 응답 목록은 「전체」일 때 제외 처리한 응답까지 보여 줍니다.)
- 엑셀 내려받기도 같은 범위로 만들어지며, 요약 시트에 적용한 응답 범위가 적힙니다. 과목별 설문은 한 파일에 응답·문항별 통계·과목별/교수별 평균·원자료·서술형과 계열·학년·반·교수·과목·이론/실습별 비교 시트(`비교-…`)가 들어갑니다.

## 4-15. 우수 참여 반 산출
- 「대상 인원」 탭의 「반별 재적 인원」에 반별 인원을 입력하거나 엑셀(열 이름: 계열·학년·반·재적인원)로 올린 뒤 우측 상단 「저장」을 누릅니다. (설문 정의 `def.classHead`에 저장되며 DB 변경은 필요 없습니다.)
- 결과 보기 → 비교 탭 맨 위에 「우수 참여 반」이 표시됩니다.
  1. 유효 응답(점검 문항 통과 · 직선 응답 제외 · 관리자 제외 아님)만 인정합니다.
  2. 반별 응답률 = 유효 응답 수 ÷ 재적 인원. 응답률을 정수 %로 반올림해 같은 구간이면 동급으로 봅니다.
  3. 동급이면 서술형 답변의 총 글자 수가 많은 반이 앞섭니다. 그래도 같으면 유효 응답 수가 많은 반 순입니다.
- 같은 화면에 최고 평가 영역·문항·교수(응답 5건 이상)도 함께 나옵니다. 엑셀에는 「우수 참여 반」 시트(전체 반 순위)가 들어갑니다.
- 설문 대상이 아닌 계열·학년(예: 항공정비계열 3학년)은 과목을 등록하지 않고 배포 인원을 0명으로 두면 응답률·순위에서 빠집니다.
- 재적 인원이 없는 반은 순위에서 뒤로 가며 「재적 인원 미등록」으로 표시됩니다. 전체 순위의 정확도는 재적 인원 입력에 달려 있습니다.

## 4-16. 계열·반·재적 인원·과목·교수 일괄 양식 (AI 없이 불러오기)
- 「과목·교수」 탭의 **엑셀 양식 다운로드**: 계열 · 학년 · 반 · **재적인원(명)** · 과목명 · 구분 · 담당교수 열이 있는 빈 양식입니다. 재적인원은 반의 첫 행에만 적어도 됩니다.
- **현재 내용으로 양식 받기**: 지금 등록된 과목·교수와 반별 재적 인원이 채워진 파일입니다. 다음 학기에는 이 파일에서 과목·교수·인원만 고쳐 올리면 됩니다.
- **엑셀 업로드**: 파일을 올리면 미리보기에서 신규·갱신·동일과 오류(중복, 같은 반의 인원 값 불일치)를 확인한 뒤 「등록」을 누릅니다. 등록 방식은 「추가·갱신」 또는 「전체 교체」입니다. AI 호출 없이 양식의 열 이름만으로 읽습니다.
- 등록하면 과목·교수는 목록에, 반별 재적 인원은 설문 정의(`def.classHead`)에 저장되고, 계열·학년별 배포 인원은 반별 인원의 합으로 자동 계산됩니다. (「배포인원」 시트를 따로 올리면 그 값을 우선합니다.)
- 「대상 인원」 탭은 따로 쓰지 않습니다. 「과목·교수」 목록의 「재적 인원」 열에서 반별 인원을 바로 고칠 수 있고, 저장하면 계열·학년별 배포 인원이 자동으로 다시 계산됩니다. (반별 인원이 없는 이전 설문에만 「대상 인원」 탭이 남아 있습니다.)
- 열 이름은 설문의 연동 목록 설계(열 이름)를 따릅니다. 설계를 바꾸면 양식을 다시 받으십시오.

## 5. 개인정보·운영 유의사항
- 이름·연락처·주소·위치·서명·첨부를 받는 문항이 있으면 **「동의 체크」 문항**(수집 항목·목적·보유 기간·거부 시 불이익)을 반드시 넣으십시오. (개인정보 보호법 제15조) 동의 문항이 없으면 문항 탭에 경고가 표시됩니다.
- 첨부·사진·서명은 DB 용량을 사용합니다(무료 500MB). 사진은 올리기 전에 자동으로 줄이며 응답 1건당 총 15MB 이내입니다.
- 행사 후 엑셀로 원자료를 내려받아 보관하고, 불필요한 설문은 삭제해 용량을 확보하십시오.

## 6. 알려진 한계
- 현재 위치 → 주소 변환은 OpenStreetMap(참고용)이며 정확도가 낮을 수 있습니다. 확정은 도로명 검색으로 합니다.
- 카카오 우편번호·jsQR 등 외부 스크립트가 차단되면 주소는 직접 입력, QR은 코드 직접 입력으로 대체됩니다.
- 이미지·PDF 입력은 index.html에 설정한 AI 제공자가 지원할 때만 동작합니다. 실패하면 docx·텍스트로 올리십시오.
- 과목별 평가의 「과목·교수 현황판」은 5점 척도(likert5) 문항을 전제로 합니다. (리포트·이력 비교는 형식 제한 없음)
