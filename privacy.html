제1조 개요

아세아항공직업전문학교(이하 "학교")가 운영하는 ASEA 업무캘린더 (이하 "서비스")는 임직원의 업무 일정 관리를 위한 내부 웹 애플리케이션입니다.

본 방침은 서비스가 수집·이용·보관·파기하는 개인정보의 처리 기준을 규정하며, 「개인정보 보호법」 및 관련 법령을 준수합니다.

📌 본 서비스는 Google OAuth 2.0을 통해 Google 계정으로만 로그인합니다. 별도의 비밀번호를 수집·저장하지 않습니다.

제2조 수집하는 개인정보 항목 및 수집 방법

① 수집 항목

구분항목수집 시점
Google 계정 정보 이메일 주소, 프로필 이름 Google 로그인 시 자동 수집
Google Calendar 데이터 일정 제목, 날짜·시간, 설명, 참석자 서비스 이용 중 Google Calendar API를 통해 접근
업무 입력 데이터 업무 보고, 메모, 부서 태그 등 사용자가 직접 입력한 정보 서비스 이용 중

② 수집 방법

  • Google OAuth 2.0 인증 동의를 통한 자동 수집
  • 사용자의 직접 입력

③ 민감정보 수집 여부

본 서비스는 민감정보(사상·신념, 건강, 범죄 이력 등)를 수집하지 않습니다.

제3조 개인정보의 수집·이용 목적

목적사용 정보
사용자 인증 및 로그인 Google 계정 이메일, 프로필
업무 일정 조회·등록·수정·삭제 Google Calendar 데이터
주간업무보고 생성 및 배포 일정 데이터, 이메일 주소
서비스 내 기능 제공 (대관, 차량, 인사 등) 사용자 입력 데이터

수집된 정보는 위 목적 외에 사용하지 않으며, 목적 변경 시 사전 동의를 받습니다.

제4조 Google API 데이터 사용 고지

본 서비스는 Google Calendar API 및 Google OAuth 2.0을 사용합니다. Google API 사용을 통해 수집된 정보는 아래 원칙을 따릅니다.

  • Google API로 수집한 데이터는 서비스 기능 제공 목적으로만 사용합니다.
  • 광고, 데이터 판매, 제3자 제공 등 상업적 목적으로 사용하지 않습니다.
  • 사람이 직접 읽는 경우는 오직 사용자 본인의 요청 또는 법적 의무가 있을 때에 한합니다.
  • Google의 API 서비스 사용자 데이터 정책을 준수합니다.
🔒 본 서비스는 Google API로 얻은 데이터를 외부 서버로 전송하거나 저장하지 않습니다. 모든 데이터는 사용자의 브라우저 내(localStorage) 또는 사용자 본인의 Google 계정에 저장됩니다.

제5조 개인정보의 보유 및 이용 기간

데이터 유형보유 위치파기 방법
Google OAuth 토큰 사용자 브라우저 메모리 (세션) 브라우저 종료 또는 로그아웃 시 자동 삭제
업무 입력 데이터 사용자 브라우저 localStorage 브라우저 데이터 삭제 또는 사용자가 직접 삭제 시
Google Calendar 일정 사용자 본인의 Google 계정 Google 계정에서 직접 삭제

서비스 탈퇴(Google 앱 권한 해제) 시 서비스는 더 이상 사용자의 Google 데이터에 접근할 수 없습니다. Google 계정 권한은 Google 계정 보안 설정에서 해제 가능합니다.

제6조 개인정보의 제3자 제공

본 서비스는 사용자의 개인정보를 외부에 제공하지 않습니다. 단, 다음의 경우는 예외입니다.

  • 사용자가 사전에 동의한 경우
  • 법령에 의거하거나 수사 목적으로 법령에 정해진 절차에 따라 요청된 경우

제7조 사용자의 권리

사용자는 언제든지 다음의 권리를 행사할 수 있습니다.

  • 열람권: 본인의 개인정보 처리 현황 열람 요청
  • 정정·삭제권: 잘못된 정보의 수정 또는 삭제 요청
  • 처리 정지권: 개인정보 처리의 정지 요청
  • 동의 철회: Google 계정 앱 권한에서 언제든지 액세스 권한 해제 가능

권리 행사는 아래 개인정보 보호 담당자에게 연락해 주시기 바랍니다.

제8조 개인정보 보호를 위한 기술적·관리적 조치

  • 모든 통신은 HTTPS(TLS)로 암호화됩니다.
  • Google OAuth 2.0 표준 프로토콜을 사용하여 비밀번호를 직접 취급하지 않습니다.
  • Google API 접근 토큰은 브라우저 세션에만 유지되며 서버에 저장되지 않습니다.
  • 최소 권한 원칙(Least Privilege)에 따라 필요한 API 권한만 요청합니다.
