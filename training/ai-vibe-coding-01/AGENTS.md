# ASEA 교직원 AI 개발 지침 (실습용)
1. 이 저장소는 교직원 교육용이다. 운영 중인 학사정보시스템이나 기존 ASEA 웹앱을 수정하지 않는다.
2. 개발 전에 DESIGN_SYSTEM.md와 css/tokens.css를 읽고 일관된 색상·글꼴·간격을 적용한다.
3. 기본 기술은 HTML, CSS, JavaScript로 한다. 설치나 과금이 필요한 도구는 필수로 가정하지 않는다.
4. 요구사항을 먼저 요약하고, 작업 범위와 변경 예정 파일을 설명한다.
5. 메모 예제의 저장은 브라우저 localStorage를 사용하며 실제 학생·교직원 개인정보는 저장하지 않는다.
6. 기능 변경 후 등록·수정·삭제·새로고침 유지·모바일 표시를 확인한다.
7. API 키, 비밀번호, 토큰, 실제 학적정보를 소스·로그·포럼에 포함하지 않는다.
8. GitHub 반영 또는 배포 전에 변경사항을 사용자에게 설명한다. 기존 파일 삭제나 대량 수정은 사전 확인한다.
9. Claude Code와 Codex 등 도구별 기능·권한 차이를 인정하며 특정 유료 기능을 필수로 요구하지 않는다.
