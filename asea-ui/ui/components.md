# 02. 컴포넌트

마크업은 `ui/gallery.html`에 그대로 있습니다. 값은 survey.html·style.css(`.sv-*`)·aseasurvey.css·budget-app.css·task.css 실측입니다.

## 1. 헤더 (sticky)

- 높이 56px, 흰 배경, 아래 1px 테두리 + `sh`, `position: sticky; top: 0; z-index: 100`, 좌우 20px, 요소 간격 10px.
- 구성: 22px 주색 아이콘 → 로고(16px/700/-0.3px) → 부제(12px, 보조색) → 오른쪽 끝(`margin-left:auto`) 스와치·사용자(아바타 28px 원 + 이름 13px + 로그아웃 24px 높이 외곽 버튼).
- 모바일(<640px): 좌우 12px. 부제는 숨겨도 됩니다.
- 변형: 설문 학생 화면 `.hdr`(배경이 설문별 색, 로고는 대비에 따라 흑백 전환), 시험 모드 띠 `.testbar`(황색 배경·가운데 정렬·13px·500).

## 2. 버튼

| 종류 | 배경 | 글자 | 테두리 | 호버 |
|---|---|---|---|---|
| primary | 주색 | 흰색 | 없음 | 배경 `#1557B0` |
| secondary | 흰색 | 주색 | 1px `#E8EAED` | 배경 `#E8F0FE` + 테두리 주색 |
| ghost | 투명 | 보조색 | 없음 | 배경 `#E8F0FE` + 글자 주색 |
| danger | 빨강 | 흰색 | 없음 | 밝기 .92 |
| danger-o | 흰색 | 빨강 | 1px 빨강 | 배경 `#fee2e2` |
| icon | 투명 32×32 | 보조색 | 없음 | 배경 `#EEF1F4`(삭제는 빨강 연함) |

- 공통: 6px, 패딩 8×16, 14px/600, 높이 37px, 아이콘 간격 6px, `transition .18s`.
- 눌림 `translateY(1px)`(.06s), 비활성 opacity .5 + `not-allowed`, 처리중 `.busy`(왼쪽에 14px 스피너, 클릭 차단).
- 작은 크기 12px·높이 30px. 모바일 터치 높이 44px.
- 문구는 **동사형**('저장', '삭제', '문항 추가'). 위험 동작은 확인창을 거칩니다.
- 보조 동작: `.ux-link`(밑줄 링크 버튼), `.ux-add`('+ 항목 추가', 12.5px/600 주색).
- 분할 버튼 `.ux-seg`: 1px 테두리 묶음, 선택 항목 주색 배경·흰 글자.

## 3. 입력

- 6px, 패딩 8×12, 14px, 배경 `#FAFBFE`, 테두리 1px `#E8EAED`.
- **포커스**: 테두리 주색, 3px 링(주색 15%), 배경 흰색, `transition .15s`.
- 오류: 테두리 빨강 + 배경 `#fee2e2` + 아래 11px 빨강 안내.
- 숫자: `.num` 오른쪽 정렬·tabular-nums. 금액은 천 단위 쉼표(budget-app.js 전역 `input` 처리기).
- 라벨 위쪽 12px/500 보조색, 필수는 문구로 표시. 힌트 11px 보조색.
- 인라인 편집 `.ux-inline-edit`: 평소 테두리 투명, 포커스 시 아래 1px 주색 선(문서 제목·옵션 입력).
- 선택지 `.ux-choice`: 1.5px 테두리, 높이 48px, 선택 시 주색 배경·흰 글자·700, 눌림 `scale(.97)`. 5점 척도는 한 줄 5칸.
- 체크박스/라디오 표식: 라디오 13px 원(2px `#C2CAD3`), 체크는 6px 사각.

## 4. 칩·배지·태그·카운트

- 칩/태그: 6px, 11px/700, 패딩 2×7. 종류 색: blue·green·orange·red·gray(연한 배경+진한 글자). 섹션 태그는 주색 배경·흰 글자, 설명 태그는 `#F6C344`.
- 알림 배지: 16px 원 빨강 배경·10px 흰 글자.
- 알림 박스 `.ux-alert`: 6px, 패딩 10×14, 13px, info(주색 연함)·warn·err·ok. 앞에 18px 아이콘.

## 5. 탭·단계

- 탭: 아래 1px 전체 선 위에 3px 활성선(주색). 활성은 700·`accent-dk`. 가로 스크롤(`overflow-x:auto`), 좌우 화살표 이동, 선택값은 `localStorage`로 기억(`UX.tabs(root, key)`).
- 단계 표시 `.ux-steps`: 24px 원 번호, done=초록, cur=주색 채움. 업무 진행 단계(task.css)는 6칸 그리드 버튼(36px 높이, 완료 연한 주색, 현재 주색 채움).
- 업무 상단 탭 변형(task.css `.tabs`): 높이 50px 헤더 안, 활성 2px 아래선.

## 6. 카드

| 변형 | 특징 |
|---|---|
| 기본 | 흰색·1px 테두리·6px·`sh`·패딩 16 |

## 7. 편집 카드(survey 편집기 핵심)

- 패딩 `12px 38px 12px 26px`(왼쪽 핸들·오른쪽 삭제 자리). 왼쪽 중앙 `⋮⋮` 핸들(`#B6BDC8`, `cursor:grab`), 오른쪽 위 삭제 ×(opacity .55 → 1, 호버 빨강).
- 헤더 행: 번호(13px/700 주색) → 종류 태그 → 제목 입력(14px/600, 최소 140px) → 종류 선택(12px).
- 드래그 중 원본 opacity .45, 놓을 위치는 **3px 주색 막대**(위/아래 반쪽 기준, 위 -5px/아래 -5px).
- 섹션 머리 접기: 셰브론이 `rotate(-90deg)`(.18s), 머리 호버 배경 주색 연함 + 셰브론 주색, 상태 `localStorage`.
- 하단 작업 바 `.ux-ed-foot`: 위 1px 선, 버튼 간격 8px, 줄 바꿈 허용.

## 8. 로그인·진입 카드

가운데 정렬 카드(폭 420~440px, 패딩 24~28px, 요소 간격 12~14px), 제목 20px, Google 버튼 높이 44px. 관리자는 비밀번호 입력 + 보조 링크. 승인 대기·오류 안내는 알림 박스로 카드 안에 둡니다. 부서·반 비밀번호 로그인(budget·aseasurvey-admin)도 같은 틀입니다.

## 9. 상태 화면

- 로딩: 36px 스피너(3px `#E8EAED` 테두리, 위쪽만 주색, .8s) + 15px 보조색 문구. 화면 전체 덮을 때 `rgba(255,255,255,.92)` 막.
- 빈 화면: 가운데 정렬, 14px/500 보조색, 위아래 24px. 다음 행동 버튼을 함께 둡니다.
- 스켈레톤: 1.4s 그라데이션 흐름, 6px.
- 사용자 아바타: 28px 원, `object-fit: cover`.

## 10. 로그·타임스탬프·변경 이력
