## 2. 테마 (색상 3종)

`<html data-ux-theme="aurora">` 처럼 지정합니다. 스와치 버튼(20×20, 6px)을 헤더에 두고 `UX.theme(name)`을 호출하면 `localStorage`(`ux-theme`)에 저장됩니다.

| 테마 | accent | accent-dk | accent-lt | bg | border |
|---|---|---|---|---|---|
| sky(기본) | `#1A73E8` | `#1557B0` | `#E8F0FE` | `#F0F9FF` | `#E8F0FE` |
| aurora | `#8B5CF6` | `#7C3AED` | `#EDE9FE` | `#F5F3FF` | `#C4B5FD` |
| mint | `#10B981` | `#059669` | `#D1FAE5` | `#ECFDF5` | `#A7F3D0` |

스와치 선택 표시: `box-shadow: 0 0 0 2px #fff, 0 0 0 3.5px #202124`, 호버 `scale(1.15)`(.15초).

참고: 저장소의 `appear-head.js`(`AppApply`)는 별도의 '외관 설정'(blue/green/purple/rose, 반지름 상한 6, 그림자 프리셋)을 모든 페이지에 적용하고 `site-admin.js`가 클라우드 동기화합니다. survey.html에서는 이 시트가 화면 하단에 겹쳐 보이는 것이 정상입니다.

## 3. 다크 모드

`<html data-theme="dark">`. `ui-kit.css`의 다크 토큰: 배경 `#0f1115`, 카드 `#1a1d24`, 글자 `#e8eaed`, 테두리 `#2c313a`. `UX.dark(true)`가 저장(`ux-dark`)합니다. 기존 페이지는 `html[data-theme="dark"]` 또는 `prefers-color-scheme: dark` 중 한 가지를 쓰므로 새 페이지는 **수동 속성 방식**을 따릅니다.

## 5. 간격·크기

간격 단위: 4·8·12·16·20·24·32·48px. 카드 안 여백 12~20px, 카드 간격 9~12px, 페이지 좌우 16px, 본문 최대폭 1100px(설문 학생 화면 780px).

| 요소 | 크기 |
|---|---|
| 헤더 | 높이 56px, 좌우 20px, 요소 간격 10px, 아래 1px 테두리 + 얕은 그림자 |
| 기본 버튼 | 높이 37px, 패딩 8×16 |
| 작은 버튼 | 높이 30px, 패딩 6×14, 12px |
| 터치 버튼(모바일) | 높이 44px |
| 아이콘 버튼 | 32×32 |
| 입력 | 패딩 8×12, 6px |

## 6. 모서리·그림자

- 모서리 **6px 하나**. 원(아바타·점·스피너)만 50%.
- 그림자 4단: `sm`(카드 기본) · `md`(호버·토스트) · `lg`(모달·서랍) · `card`(설정 카드, 테두리 없는 카드).

## 7. 모션 토큰

| 토큰 | 값 | 쓰임 |
|---|---|---|
| fast | .12s | 행·섹션 머리 호버 배경 |
| base | .15s | 입력 테두리·카드 그림자·스와치 |
| button | .18s | 버튼 배경·테두리 |
| slow | .25s | 막대 너비·서랍 |
| accordion | .32s | 아코디언 높이(`grid-template-rows`) |
| spin | .8s linear infinite | 스피너 |
| ease-out | `cubic-bezier(.22,1,.36,1)` | 모달·서랍·토스트 등장 |

`prefers-reduced-motion: reduce`에서는 모든 애니메이션·전환을 사실상 0으로 만듭니다.

## 8. z-index 스케일

헤더 100 · 하단 작업 바 60 · 모달 1000 · 토스트 1100. 기존 페이지에는 9000~100001대도 있어, 새 페이지는 위 값을 씁니다(`docs/token-audit.md`).

## 9. 반응형·접근성

- 분기점: 600 / 640 / 768 / 900 / 1024 / 1180. 키트는 640 하나만 씁니다(모달은 아래에서 올라오는 시트, 버튼 44px, 막대 라벨 축소).
- 포커스: 키보드 `outline: 2px solid accent; offset 2px`, 입력은 테두리+3px 링.
- 탭은 `role="tab"`·`aria-selected`·좌우 화살표, 접기는 `role="button"`·`aria-expanded`, 모달은 `role="dialog"`·`aria-modal`, 토스트는 `aria-live="polite"`.
- 터치 대상 최소 44px(모바일). 색만으로 상태를 전달하지 않습니다.
- 인쇄: 헤더·하단 바·토스트 숨김, 카드 그림자 제거·쪽 나뉨 방지.
