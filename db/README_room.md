# 링크형 업무방(room.html) 설치·사용 안내

## 주소
- 참여자: `room.html?r=<링크 토큰>` — 링크만 있으면 누구나 보고, 이름을 입력하면 쓸 수 있습니다(로그인 불필요).
- 관리자·개설자: `room-admin.html` — Google 로그인(업무진행 평가툴과 같은 `task-auth`).

## 서버 설치 (운영 DB `asea-workspace`에는 이미 적용됨)
1. Supabase SQL Editor에서 `db/room_schema.sql` 실행(여러 번 실행해도 안전). `rm` 스키마, `public.rm_*` RPC 19개, 비공개 저장소 버킷 `room-files`(20MB)가 만들어집니다. 사전 조건: `db/task_schema.sql`(관리자 로그인용 `tsk` 스키마).
2. Edge Function `room-file` 배포: `supabase/functions/room-file/index.ts` (JWT 검증 켬). 업로드·열람 주소 발급과 휴지통 정리를 맡습니다.
3. 방 만들기: `room-admin.html` 에서 「방 만들기」. 방 개설자는 관리자가 같은 화면의 「방 개설자 지정」에 Google 이메일을 추가합니다.

## 권한 구조
| 구분 | 방식 |
|---|---|
| 보기 | 링크(40자 무작위 토큰)를 아는 사람 누구나 |
| 쓰기 | 링크 + 이름 입력(입장). 방 설정이 「링크로 보기만」이면 쓰기 불가 |
| 이름 보호 | PIN 숫자 4자리(선택). PIN 이 있는 이름은 PIN 없이 쓸 수 없고, 5회 틀리면 15분 잠깁니다. PIN 은 해시로만 저장 |
| 방 설정·잠금·링크 재발급·휴지통 정리 | 관리자 또는 그 방의 개설자(Google 로그인) |

- 링크가 유출되면 관리자가 「즉시 잠금」 또는 「링크 재발급」(기존 링크 즉시 무효)을 합니다.
- 삭제는 휴지통으로 이동하며 누구나 복구할 수 있고, 영구 삭제는 관리자 화면의 「휴지통 정리(30일 지난 것)」로 실행합니다. 자동 예약 삭제는 아직 없습니다.
- 파일: 이미지(png·jpg·gif·webp)·PDF는 미리보기, 문서(doc·docx·xls·xlsx·ppt·pptx·hwp·hwpx·txt·csv)는 내려받기. 실행 파일·HTML·SVG·압축 파일은 올릴 수 없습니다. 큰 이미지는 브라우저에서 2560px 이하로 줄여 올립니다. 파일 주소는 1시간짜리 서명 주소이고 저장소는 비공개입니다.
- 알림: 방 안 알림함(담당 지정·단계 이동)과 변경 피드, 탭이 열려 있을 때의 브라우저 알림. 탭이 닫힌 상태의 푸시, 메일 자동 발송, 카카오톡은 2차입니다.
- 변경 반영은 6초마다 확인합니다. 같은 업무를 동시에 고치면 나중 저장은 「다른 사람이 먼저 수정」으로 거절되고 최신 내용을 다시 불러옵니다.

## 주의
- 링크 쓰기 방식이므로 학번·연락처 등 개인정보를 올리지 않는 것을 원칙으로 합니다(방 상단에 안내 표시).
- 방 링크가 주소창에 들어 있으므로 외부로 노출되지 않도록 `referrer` 를 보내지 않게 해 두었습니다. 단체 채팅방 등에 링크를 공유할 때는 그 방 참여자가 곧 접근자임을 유의하십시오.
- 운영 DB 적용 도구가 긴 plpgsql 함수나 DELETE 문에서 시간 초과가 나는 일이 있어, DELETE 는 SQL 함수(`rm.purge_rows`, `rm.drop_creator`)로 분리해 두었습니다.
